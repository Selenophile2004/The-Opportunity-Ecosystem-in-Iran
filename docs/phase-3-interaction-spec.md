# مشخصات تعامل فاز ۳

## طرح صفحه مدل

صفحه مدل باید به یک «رشتهٔ شواهد» شبیه باشد: زمینه و وضعیت در ستون ثابت، و رکوردهای منبع در ردیف‌های پیوسته. شماره اسلاید نقش index واقعی را دارد؛ شماره‌گذاری تزئینی اضافه نمی‌شود.

```text
┌──────── header: ILIA / back / locale ─────────────────────────────┐
│ breadcrumb                                                       │
│ title + status + source range       navigation across 9 blocks   │
├─────────────────────┬─────────────────────────────────────────────┤
│ topic map / filters │ slide trace                                │
│                     │ ── source item ── title ── preview          │
│                     │ ── source item ── title ── preview          │
└─────────────────────┴─────────────────────────────────────────────┘
                                    ╲ animated SVG connector
                                      ╲┌──────── detail panel ─────┐
                                       │ body / relations / source │
                                       └───────────────────────────┘
```

## قواعد بصری

- پالت همان Quiet Signal است: `#09132A`، `#170427`، `#0E0A12`، `#FFFFFF` و `#FFC000`.
- ردیف‌های محتوا سطح مستقل و shadow ندارند؛ خط source آن‌ها را به یک جریان واحد وصل می‌کند.
- تنها عنصر پرقدرت modal است؛ پس‌زمینه هنگام بازشدن dim/blur می‌شود.
- متن فارسی راست‌چین و متن انگلیسی چپ‌چین است؛ طول ستون خواندن زیر ۸۰ کاراکتر می‌ماند.
- ترجمهٔ موجودنبودن محتوا با پیام روشن نشان داده می‌شود و متن فارسی در locale انگلیسی تزریق نمی‌شود.

## modal و deep link

- کلیک روی هر ردیف `detail=<stable-id>` را به URL اضافه می‌کند.
- محتوای کامل modal از route داخلی داده و به‌صورت lazy واکشی می‌شود.
- خط SVG با اندازه‌گیری زندهٔ مبدأ و لبهٔ panel ساخته می‌شود و روی resize/scroll دوباره محاسبه می‌شود.
- در فارسی panel از راست و در انگلیسی از چپ باز می‌شود.
- Escape، backdrop و دکمه بستن فعال‌اند؛ focus داخل dialog محصور و پس از بستن به ردیف مبدأ برگردانده می‌شود.
- type-on فقط برای خلاصهٔ کوتاه است، با کلیک کامل می‌شود و در reduced motion اجرا نمی‌شود.
- در mobile panel تمام‌صفحه است و connector تزئینی حذف می‌شود.

## بازبینی ضدالگو

طرح اولیه می‌توانست به grid کارت‌های هم‌شکل تبدیل شود. آن مسیر کنار گذاشته شد چون سلسله‌مراتب اسلاید و provenance را پنهان می‌کرد. نسخه نهایی از خود شماره اسلاید، نوع رکورد و رابطهٔ داده به‌عنوان عناصر ساختاری استفاده می‌کند؛ badge و border فقط وقتی اطلاعات وضعیت را منتقل می‌کنند به کار می‌روند.
