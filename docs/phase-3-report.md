# گزارش فاز ۳ — صفحات مدل و جزئیات تعاملی

تاریخ تحویل: ۱۴۰۵/۰۶/۱۹ (2026-09-10)

## نتیجه

قالب منعطف صفحهٔ مدل برای هر ۹ بلوک بوم پیاده‌سازی شد. هر صفحه دادهٔ واقعی مدل محتوا را نمایش می‌دهد، وضعیت و بازهٔ اسلایدهای منبع را صریح نگه می‌دارد و برای بلوک‌های فاقد داده، empty state صادقانه دارد. صفحهٔ «کانال‌ها» در نسخهٔ فارسی ۲۳ رکورد متصل به منبع را ارائه می‌کند.

## پیاده‌سازی

- هدر، breadcrumb، عنوان، وضعیت، شمار رکورد و بازهٔ اسلاید برای هر بلوک
- ناوبری میان ۹ بلوک بدون ایجاد قالب‌های جداگانه
- جست‌وجوی محلی و فیلتر persona با همگام‌سازی URL
- ردیف‌های evidence به‌جای card grid، با عنوان، پیش‌نمایش، نوع و provenance
- topic map برای گره‌های معنایی استخراج‌شده
- API جزئیات با بارگذاری lazy و شناسهٔ پایدار محتوا
- مودال deep-linked با state به شکل `?detail=<content-id>`
- پنل راست برای فارسی و چپ برای انگلیسی؛ تمام‌صفحه در موبایل
- بستن با Escape، دکمه و پس‌زمینه؛ focus trap، بازگردانی focus و قفل scroll
- متن type-on کوتاه با امکان تکمیل فوری و احترام به `prefers-reduced-motion`
- اتصال SVG زنده میان رکورد و پنل جزئیات در desktop
- نمایش صریح وضعیت بازبینی ترجمه در محتوای انگلیسی

## QA

Build تولیدی Next.js و بررسی TypeScript موفق بودند. تست مرورگری production با Chrome نصب‌شده روی Windows روی پورت ایزولهٔ ۳۱۰۰ اجرا شد و هر ۹ سناریو را گذراند:

1. نمایش ۲۳ رکورد منبع‌دار کانال‌ها در فارسی
2. جست‌وجوی محلی و state آدرس
3. فیلتر persona و روابط مدل
4. بارگذاری lazy مودال، deep link، منبع و SVG connector
5. focus trap، Escape و بازگردانی focus
6. ورود مستقیم با deep link و بستن از پس‌زمینه
7. پنل LTR انگلیسی و وضعیت صادقانهٔ ترجمه
8. empty state بلوک فاقد داده
9. مودال تمام‌صفحهٔ موبایل و حذف connector تزئینی

هیچ `console.error` یا `pageerror` در اجرای نهایی ثبت نشد. تصاویر QA در `artifacts/phase3/` نگهداری می‌شوند.

## مرز فاز

نمودارها و drill-down تحلیلی در فاز ۴ قرار دارند. در فاز ۳ فقط نوع visualization ثبت‌شده در مدل نمایش داده می‌شود و هیچ عدد یا نمودار ساختگی تولید نشده است. بازبینی انسانی ترجمهٔ بدنهٔ ۱۵۵ گره انگلیسی نیز backlog محتوایی باقی می‌ماند.
