# مسیرهای بصری فاز ۲

## مبنای تصمیم

موضوع محصول یک «نقشهٔ تصمیم» برای اکوسیستم فرصت است، نه داشبورد عملیاتی و نه بازنمایی اسلایدها. تصویر Mindway فقط سه ویژگی قابل انتقال دارد: سطح تیره و آرام، تمرکز محتوا در یک ناحیه و لوگوی بزرگ در فضای منفی. تصاویر Canvas نیز فقط topology واقعی ۹ بلوک را تعیین می‌کنند.

## مسیر A — Quiet Signal (منتخب)

بوم مانند یک ابزار تحلیلی دقیق روی سطح مات دیده می‌شود. watermark بزرگ ILIA در فضای آزاد قرار می‌گیرد و طلایی فقط هنگام انتخاب یا تطبیق داده ظاهر می‌شود. مرزها به‌جای کارت‌های مستقل، شبکهٔ واحد Canvas را می‌سازند.

```text
┌──────────────────────── header / search / locale ───────────────────────┐
│  ILIA watermark                 عنوان + context                         │
│  در فضای منفی              ┌──── canvas topology واقعی ─────────────┐   │
│                            │ partner│act/res│ value│rel/ch│segment │   │
│  فیلترهای کم‌ارتفاع        ├───────────────┬───────────────────────┤   │
│                            │ cost          │ revenue               │   │
│                            └────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
```

- رنگ: `#09132A`، `#170427`، `#0E0A12`، `#1B1510`، `#FFFFFF`، `#FFC000`
- تایپ: Yekan Bakh محلی برای فارسی؛ Inter/Arial fallback برای انگلیسی
- تراز: متن فارسی راست‌چین؛ Canvas از نظر هندسی مستقل از جهت زبان
- امضای بصری: فقط «رد طلایی» انتخاب، نه glow دائمی

## مسیر B — Golden Circuit

روابط بلوک‌ها با خطوط و nodeهای طلایی دائمی نشان داده می‌شوند. این مسیر ظرفیت خوبی برای نمایش اتصال دارد، اما در لندینگ تمرکز را از topology و وضعیت داده می‌گیرد و خطر شباهت به داشبوردهای نئون دارد.

```text
watermark ──●── block ──●── block
             ╲             ╱
              ●── filters ●
```

## مسیر C — Editorial Atlas

یک روایت متنی و فهرست‌محور در کنار نسخهٔ کوچک Canvas قرار می‌گیرد. برای گزارش خواندنی مناسب است، اما «Canvas به‌عنوان نقطه شروع محصول» را تضعیف می‌کند و drill-down را به ناوبری ثانویه تبدیل می‌کند.

```text
عنوان و روایت بلند               canvas کوچک
──────────────────               ┌──────────┐
فهرست مدل‌ها و منابع             │ 9 blocks │
                                  └──────────┘
```

## انتخاب و بازبینی انتقادی

مسیر Quiet Signal انتخاب شد چون تنها مسیر است که هم فضای خالی و watermark مرجع Mindway را حفظ می‌کند و هم هندسهٔ واقعی Canvas را عنصر قهرمان صفحه قرار می‌دهد. برای جلوگیری از ظاهر عمومی «dark SaaS»، این موارد حذف شدند: hero آماری، مجموعه کارت‌های هم‌اندازه، gradientهای تزئینی، labelهای تمام-uppercase و motion ورودی برای تک‌تک عناصر. جسارت طراحی فقط روی topology یکپارچه و رد طلاییِ وابسته به تعامل صرف می‌شود.

## token و رفتار نهایی prototype

- سطح اصلی از gradient نمونه‌برداری‌شدهٔ مرجع روی fallback سرمه‌ای ساخته می‌شود.
- header و filter rail شفاف‌اند؛ container کارت‌مانند مستقل ندارند.
- هر بلوک `status` واقعی و شمارش اسلایدهای پشتیبان را نمایش می‌دهد.
- فیلتر پرسونا از روابط واقعی descendantها به چهار بلوک دارای داده اثر می‌گذارد.
- فیلتر وضعیت مستقیماً از `status` بلوک استفاده می‌کند.
- non-match حذف نمی‌شود و همچنان قابل دسترس است؛ opacity کاهش می‌یابد.
- transition انتخاب از همان بلوک آغاز می‌شود و reduced-motion به fade ساده کاهش می‌یابد.
