# گزارش فاز ۱ — مدل محتوا و معماری داده

تاریخ اجرا: ۱۴۰۵/۰۶/۱۹ (2026-09-10)

## وضعیت

زیرساخت مدل محتوا، بسته‌های runtime فارسی و انگلیسی، provenance، صف بازبینی، override، نسخه‌بندی، diff و اعتبارسنجی پیاده‌سازی شده است. پوشش فارسی کامل است. نسخهٔ انگلیسی از نظر ساختاری هم‌تراز است، اما ترجمهٔ کامل بدنهٔ ۱۵۵ گره هنوز نیازمند ترجمه/بازبینی انسانی است و به‌صراحت با وضعیت باز ثبت شده است.

## نتایج کمی

| سنجه | نتیجه |
|---|---:|
| گره در هر زبان | ۱۸۰ |
| اسلایدهای پوشش‌داده‌شده | ۱۴۵ از ۱۴۵ |
| گره‌های انگلیسی کامل/متن اصلی انگلیسی | ۲۵ |
| گره‌های انگلیسی نیازمند بازبینی | ۱۵۵ |
| آیتم‌های کل صف بازبینی | ۱۶۲ |
| خطای اعتبارسنجی پایه | ۰ |

هفت آیتم غیرترجمه‌ای صف بازبینی شامل سه ابهام label منبع، سه اختلاف شماره‌گذاری فهرست‌ها و وضعیت مجوز فونت Yekan است.

## تصمیم‌های کلیدی

- JSON فایل‌محور به‌عنوان source of truth مرحلهٔ MVP حفظ شد.
- شناسه‌ها و slugها میان زبان‌ها ثابت‌اند و متن/جهت صفحه محلی‌سازی می‌شود.
- محتوای ناموجود با `not_provided` نمایش داده می‌شود و جعل نمی‌شود.
- ترجمهٔ ناقص با وضعیت machine-readable ثبت می‌شود؛ متن فارسی به‌عنوان انگلیسی منتشر نمی‌شود.
- UI آینده تنها با `ContentRepository` تعامل می‌کند تا مهاجرت CMS کم‌هزینه بماند.

## اعتبارسنجی انجام‌شده

- کنترل hash فایل PPTX در برابر manifest فاز صفر
- برابری ۱۸۰ شناسه و slug در هر دو زبان
- صحت تمام parent/related/persona referenceها
- پوشش اسلایدهای ۱ تا ۱۴۵
- جلوگیری از نشت مسیر مطلق محلی
- همگامی فایل‌های split با اسناد تجمیعی
- parse کامل هر دو سند با Zod
- type-check TypeScript در حالت strict

## شرط تکمیل ترجمهٔ انگلیسی

برای بسته‌شدن کامل بخش ترجمهٔ فاز ۱، آیتم‌های `translation` در `content/review-queue.json` باید ترجمه و تأیید شوند و `pnpm content:validate:strict` بدون خطا پایان یابد. معماری و pipeline آماده‌اند تا ترجمه‌ها از طریق override یا به‌روزرسانی دادهٔ محلی‌شده وارد و در ingest بعدی حفظ شوند.
